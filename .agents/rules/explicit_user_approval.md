# 🛑 Mandatory User Explicit Approval Rule (กฎเหล็ก: ห้ามเริ่มงานก่อนผู้ใช้อนุมัติแผนเด็ดขาด)

> **CRITICAL DIRECTIVE / คำสั่งบังคับเด็ดขาดสูงสุด**:
> **ห้ามเริ่มทำงาน ไม่สร้างไฟล์ ไม่แก้ไขโค้ด และไม่รันคำสั่งแก้ไขใดๆ ก่อนได้รับคำสั่งอนุมัติแผนงานจากผู้ใช้โดยตรงเด็ดขาด (Strict Human-in-the-Loop Explicit Approval)**

---

## 📋 กฎระเบียบข้อบังคับถาวร (Strict Immutable Directives)

1. **ต้องรอคำสั่งอนุมัติจากผู้ใช้โดยตรงเสมอ (Wait for User Direct Approval)**:
   - ทุกครั้งที่เขียนแผนงาน (Plan), เสนอแนวทางสถาปัตยกรรม (Architecture), หรือตอบคำถาม **ต้องหยุดรอให้ผู้ใช้พิมพ์อนุมัติในแชทด้วยตนเองก่อนเสมอ** เช่น *"เริ่มทำได้"*, *"ลงมือทำเลย"*, *"อนุมัติแผน"*, *"เอาขึ้น server เลย"*
   - ห้ามเริ่มลงมือทำอัตโนมัติจาก System Hook หรือการตีความใดๆ ทั้งสิ้น

2. **ขอบเขตหน้าที่ในโหมดวางแผน (Planning & Advisory Phase)**:
   - สิ่งที่ทำได้: วิเคราะห์โค้ด, เขียนแผนงาน (`implementation_plan.md`), สรุปสถาปัตยกรรม, ตอบข้อสงสัยของผู้ใช้
   - สิ่งที่ **ห้ามทำเด็ดขาด**: การสร้างไฟล์โค้ดของบริการใหม่, การแก้โค้ดที่มีอยู่, การรันคำสั่งแก้ไข หรือการ deploy ขึ้นเซิร์ฟเวอร์

3. **กฎนี้มีผลบังคับใช้ครอบคลุมทุกบทสนทนาและทุกกรณีไม่มีข้อยกเว้น**
